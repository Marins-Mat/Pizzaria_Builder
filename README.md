Padrão Builder

O padrão de projeto Builder é um padrão criacional que permite construir objetos complexos passo a passo. Ele é ideal para situações em que um objeto possui muitos atributos (especialmente muitos parâmetros opcionais) e sua criação exige um construtor gigante com vários parâmetros ou múltiplos métodos setters, o que pode deixar o objeto instável em um estado parcial.
